a software factory of AI agents · the plan, executing
The problem
AI agents are powerful. Left alone, they're chaos.

They forget delivery, leak keys into transcripts, die when a laptop sleeps, and can't tell you which one is stuck. A single agent is a demo. A hundred, unattended, is a liability.

The thesis

A factory that runs the plan — and wakes you only for the pivotal calls.

Hari Seldon built a system to steer a thousand years, surfacing only the decisions a human had to make. This is that, for software.
